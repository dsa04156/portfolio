# Jinuk Jung · Portfolio

Interactive Korean systems-engineering portfolio, built with HTML, CSS, and vanilla JavaScript and hosted on GitHub Pages.

## Contents

- Precision Core hero: generated titanium/amber glass sculpture, large editable typography and subtle pointer depth
- Five project case studies, accessible native dialogs and keyboard navigation
- Responsive layouts, reduced-motion support and pointer-only hero motion
- Six original presentation images with full-screen viewing and original-size zoom
- Desktop project index and horizontal mobile tabs with role/outcome previews
- Research links to the author's public repositories

## Edit and preview

Edit index.html for content, styles.css for the base design, readability.css for typography, and showcase.css for the project explorer. campaign.css defines the black/orange section theme; precision.css implements the selected hero design and responsive layout. app.js handles case studies, images and pointer depth; showcase.js handles the accessible project selector.

Serve this folder using any static HTTP server. No build step, API keys, or new runtime dependencies are required. GitHub Pages serves the main branch root; pushing publishes updates. See DESIGN.md and design-qa.md for design decisions and validation.

## Content scope

Content comes from the author's supplied career documents and presentation materials. Performance numbers remain scoped to their project or experimental conditions. The six project images are original embedded images from the presentation (pages 7, 9 and 11): historical screenshots, architecture drawings and experiment plots, not live system data. The hero is an AI-generated conceptual sculpture. Career dates describe experience rather than asserting current employment.

Original applications, raw extracted text, home address, phone number, birth date and certificate identifiers are not included. Typography uses Google Fonts and Pretendard via jsDelivr with system fallbacks. The two hero arrows are from Phosphor Icons Core 2.1.1 (MIT, assets/icons/LICENSE).
