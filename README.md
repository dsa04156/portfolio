# Jinuk Jung · Portfolio

Interactive Korean systems-engineering portfolio. Built with HTML, CSS, and vanilla JavaScript; hosted on GitHub Pages.

## Contents

- Interactive orbital Canvas sculpture: Cloud / Edge AI / Kernel, with pause/resume and reduced-motion support
- Five project case studies, accessible native dialogs, keyboard navigation
- Responsive layouts, reduced-motion support, deferred offscreen animation
- Research links to the author's public repositories
- Six original images extracted from the author's presentation, with accessible full-screen image viewing and original-size zoom
- Five-project explorer with a persistent desktop index, horizontal mobile tabs, keyboard navigation, and role/outcome previews

## Edit and preview

Edit `index.html` for page content, `styles.css` for the base design, `readability.css` for typography, and `showcase.css` for the project explorer. `campaign.css` defines the current black/orange theme and hero layout. `app.js` contains case studies, images, and canvas interactions; `showcase.js` contains the project previews and accessible selection behavior. Serve this directory using any static HTTP server. No build step or API keys are required. See `DESIGN.md` for the reference-led design decisions.

GitHub Pages serves the `main` branch root. Pushing to `main` publishes updates.

## Content scope

Content was drawn from the author's supplied career documents and presentation materials. Performance numbers are scoped to their project or experimental conditions, described inside each project detail. Project images are the original embedded images from the author's presentation (pages 7, 9, and 11). They are historical screenshots, architecture drawings, and experiment plots, not live system data. The animated hero is a conceptual orbital sculpture. Career dates describe experience rather than asserting current employment.

Original applications, raw extracted text, home address, phone number, birth date, and certificate identifiers are not included. External typography uses Google Fonts and Pretendard via jsDelivr, with local system font fallbacks.
