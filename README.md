# Jinuk Jung · Portfolio

Interactive Korean systems-engineering portfolio. Built with HTML, CSS, and vanilla JavaScript; hosted on GitHub Pages.

## Contents

- Three-layer interactive Canvas diagram: Cloud / Edge AI / Kernel
- Five project case studies, accessible native dialogs, keyboard navigation
- Responsive layouts, reduced-motion support, deferred offscreen animation
- Research links to the author's public repositories
- Six original images extracted from the author's presentation, with accessible full-screen image viewing and original-size zoom

## Edit and preview

Edit `index.html` for page content, `styles.css` for the base design, `readability.css` for typography and readability adjustments, and `app.js` for case studies and interactions. Serve this directory using any static HTTP server. No build step or API keys are required.

GitHub Pages serves the `main` branch root. Pushing to `main` publishes updates.

## Content scope

Content was drawn from the author's supplied career documents and presentation materials. Performance numbers are scoped to their project or experimental conditions, described inside each project detail. Project images are the original embedded images from the author's presentation (pages 7, 9, and 11). They are historical screenshots, architecture drawings, and experiment plots, not live system data. The animated hero is a conceptual system-layer diagram. Career dates describe experience rather than asserting current employment.

Original applications, raw extracted text, home address, phone number, birth date, and certificate identifiers are not included. External typography uses Google Fonts and Pretendard via jsDelivr, with local system font fallbacks.
